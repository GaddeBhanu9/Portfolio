Data Science Intern

ExcelR Pvt Ltd

Jun 2026 – Present

Project: Hourly Energy Demand Forecasting & Interactive Dashboard (PJM Grid)

Developed an end-to-end forecasting solution for hourly electricity demand using 16 years of data (over 143K records), covering data remediation, feature engineering, multi-model benchmarking and an interactive Streamlit dashboard, achieving 1.00% SMAPE on a held-out test year.

  • Cleaned hourly grid data by addressing daylight saving time (DST) anomalies and missing data gaps, and engineered 15 features (calendar variables, Fourier terms, lags, rolling statistics, holiday flags).
  • Benchmarked five forecasting models (LightGBM, XGBoost, Prophet, PatchTST, Chronos) using a leakage-free train-validation-test protocol and tuned hyperparameters with Optuna.
  • Co-developed a weighted ensemble of LightGBM (55%) and XGBoost (45%), achieving 1.0012% SMAPE and 77 MW RMSE on the unseen test year.
  • Built recursive multi-step forecasting for horizons from 30 days to two years, incorporated uncertainty bands, and deployed an interactive Streamlit dashboard using GitHub.
  • Participated in sprint reviews, code reviews and stakeholder presentations alongside senior data scientists.
